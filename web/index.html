两阶段训练

Stage 1 · SFT（LoRA / DoRA）

LLaMA-Factory + DeepSpeed，仅监督 Agent 生成的查询、工具动作、证据选择、答案 token；以 Joint F1 + 证据链召回 + 工具成本联合选 checkpoint

Stage 2 · RL（GRPO / GSPO）

verl + vLLM + Ray + FSDP，真实检索环境 on-policy，每题采样 4 条完整轨迹，两阶段课程奖励

课程奖励设计

Stage 1 优化新增 supporting-fact、引用有效性、grounding

Stage 2 强化 Answer EM/F1 并保留证据约束

重复查询惩罚 冗余证据惩罚 非法动作惩罚 工具成本惩罚

配合 KL 约束、零方差 group 重采样、reward component 分布监控，抑制策略退化

# 多跳数据集生成指南

## 一、完整流程

```
种子问题（1-hop，来自 HotpotQA）
    ↓
【Step 1】用答案检索新文档（Retriever: E5 + FAISS → wiki18_100w.jsonl）
    ↓ 返回 15 个文档，过滤后得到 10 个
【Step 2】LLM 从新文档抽取 QA（gen_qa_prompt）
    ↓ 每个文档生成 5 个 QA 对
【Step 3】LLM 精炼答案（refine_prompt）
    ↓ 统一格式（如日期）
【Step 4】LLM 合并成多跳问题（merge_qa_prompt）
    ↓ 用描述性语言替换中间答案
【Step 5】四重验证（语义/推理/单文档/多文档）
    ↓ 过滤低质量问题
通过 → 输出为 2-hop 种子 → 循环扩展到 3-hop、4-hop
```

## 二、如何自己跑

### 前置条件

#### 1. 启动 Retriever 服务（需要 GPU）

```bash
cd E:/Life/1/SearchAgent/data/agenticragtracer

# 安装依赖
pip install flashrag fastapi uvicorn

# 启动 Retriever 服务（需要下载 E5 模型和 wiki18_100w.jsonl）
python retriever_serving.py --config retriever_config.yaml --port 8000 --num_retriever 10
```

**注意**：
- 需要 GPU（E5-base-v2 模型约 500MB）
- `wiki18_100w.jsonl` 需要从 AgenticRAGTracer 的 HuggingFace 数据集下载
- 启动后会占用 10 个 retriever 实例（可调整 `--num_retriever`）

#### 2. 配置 LLM API

编辑 `multihop_pipeline.py` 第 23-25 行：

```python
# DeepSeek API（推荐，便宜）
API_URL = "https://api.deepseek.com/v1/chat/completions"
API_KEY = "sk-xxx"  # 你的 DeepSeek API Key
DEFAULT_MODEL = "deepseek-chat"

# 或者 OpenAI API（贵）
# API_URL = "https://api.openai.com/v1/chat/completions"
# API_KEY = "sk-xxx"
# DEFAULT_MODEL = "gpt-4o-mini"
```

#### 3. 准备种子问题

从 HotpotQA 的 dev set 中提取 1-hop 问题，格式：

```json
{
  "id": "5a7a06935542990198eaf050",
  "question": "Which magazine was started first?",
  "refined_answer": "Arthur's Magazine",
  "contents": "\"Arthur's Magazine\"\nArthur's Magazine (1844–1846) was an American literary periodical..."
}
```

保存为 `hotpotqa_seeds.jsonl`。

#### 4. 运行生成脚本

编辑 `multihop_run.py` 第 154-156 行：

```python
INPUT_JSONL_PATH = "hotpotqa_seeds.jsonl"  # 你的种子问题文件
OUTPUT_JSONL_PATH = "output/multihop_output.jsonl"  # 输出路径
```

运行：

```bash
cd E:/Life/1/SearchAgent/data/agenticragtracer
python multihop_run.py
```

#### 5. 输出文件

```
output/
├── multihop_output.jsonl          # 所有多跳问题
├── multihop_output_hop2.jsonl     # 2-hop 问题
├── multihop_output_hop3.jsonl     # 3-hop 问题
└── multihop_output_hop4.jsonl     # 4-hop 问题
```

## 三、成本估算（DeepSeek-flash API）

### DeepSeek API 价格（2026-10）

| 模型 | 输入价格 | 输出价格 |
|------|---------|---------|
| deepseek-chat | ¥1/百万 tokens | ¥2/百万 tokens |
| deepseek-flash | ¥0.5/百万 tokens | ¥1/百万 tokens |

### 每个种子问题的 token 消耗

假设从 1-hop 扩展到 4-hop，每跳的处理：

| 步骤 | 输入 tokens | 输出 tokens | 调用次数 |
|------|------------|------------|---------|
| 抽取 QA（gen_qa_prompt） | ~800 | ~200 | 10 次/跳（10 个文档） |
| 精炼答案（refine_prompt） | ~100 | ~50 | 50 次/跳（50 个 QA） |
| 合并问题（merge_qa_prompt） | ~500 | ~150 | 50 次/跳 |
| 四重验证 | ~1000 | ~100 | 200 次/跳 |

**每跳总计**：
- 输入：800×10 + 100×50 + 500×50 + 1000×200 = 8,000 + 5,000 + 25,000 + 200,000 = **238,000 tokens**
- 输出：200×10 + 50×50 + 150×50 + 100×200 = 2,000 + 2,500 + 7,500 + 20,000 = **32,000 tokens**

**3 跳扩展（1-hop → 4-hop）**：
- 输入：238,000 × 3 = **714,000 tokens**
- 输出：32,000 × 3 = **96,000 tokens**

### 成本计算

**用 DeepSeek-flash**：
- 输入：714,000 tokens × ¥0.5/百万 = ¥0.357
- 输出：96,000 tokens × ¥1/百万 = ¥0.096
- **每个种子问题总计：¥0.453**

**生成 1000 个 4-hop 问题**：
- 需要约 1000 个种子问题（假设 50% 通过率）
- 总成本：1000 × ¥0.453 = **¥453**

**生成 5000 个 4-hop 问题**：
- 需要约 5000 个种子问题
- 总成本：5000 × ¥0.453 = **¥2,265**

### 对比：用 GPT-4o-mini

| 模型 | 输入价格 | 输出价格 | 1000 个问题成本 |
|------|---------|---------|----------------|
| DeepSeek-flash | ¥0.5/百万 | ¥1/百万 | **¥453** |
| DeepSeek-chat | ¥1/百万 | ¥2/百万 | **¥906** |
| GPT-4o-mini | $0.15/百万 | $0.60/百万 | **约 ¥750** |

**结论**：DeepSeek-flash 是最便宜的选择，生成 1000 个多跳问题约 ¥453。

## 五、常见问题

### Q1: 没有 GPU 怎么办？

**方案 1**：用 CPU 运行 Retriever（会很慢）
```yaml
# retriever_config.yaml
gpu_id: ""  # 留空，使用 CPU
```

**方案 2**：用 Tavily 在线搜索替代本地 Retriever
```python
# multihop_pipeline.py
def retrieve_docs(self, query, ...):
    # 调用 Tavily API
    response = requests.post("https://api.tavily.com/search", ...)
```

### Q2: API 限速怎么办？

```python
# 减少并行线程数
max_workers=50  # 从 200 减少到 50

# 添加延迟
import time
time.sleep(0.1)  # 每次调用后等待 0.1 秒
```

### Q3: 生成的问题质量不高？

- 检查 Retriever 是否返回了相关文档
- 检查 LLM 是否正确理解了提示词
- 增加验证的严格程度
- 使用更强的 LLM（如 deepseek-chat 或 gpt-4o）
